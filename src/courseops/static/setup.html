Station roles

The kinds of job a person does at this event. Rename these to your own wording, and add any the list is missing — a Liaison embedded with Public Safety, say.

The seven that come with a new event have their own status wording: an aid station is "Torn down" where a sweep is "Finished". A role you add uses "Not started / Active / Closed".
