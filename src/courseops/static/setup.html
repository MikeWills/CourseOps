Place layers

Whatever kinds of place this event has. Organizers draw different things — mile markers, medical, traffic control, portable toilets — so this list is yours, and there is no limit on it. Each one is a layer that can be turned on and off on the map. The switches appear in this order - drag the grip to put the ones people reach for at the top.

Station roles

The kinds of job a person does at this event. Rename these to your own wording, and add any the list is missing — a Liaison embedded with Public Safety, say.

The seven that come with a new event have their own status wording: an aid station is "Torn down" where a sweep is "Finished". A role you add uses "Not started / Active / Closed".

Leaders we track

A way to follow particular types of racer round the course. Most events want the first man and the first woman; add a wheelchair leader, a first junior, or whatever your race awards, and delete any you do not track.

Each one shows as a row per race on the Net Control screen, so two leaders and three races is six rows. Name them the way they will be read on the air. Reports are recorded against a leader, so one that has already been sighted cannot be deleted until those reports are cleared.

Live tracking

Whether this event is connected to APRS-IS and storing positions. Turn it on for the event, and for a check-in rehearsal beforehand.

Leave it off the rest of the time. The filter asks for each operator's callsign wherever they are, not just on the course — so a feed left running records where your volunteers are every day, which is not what anyone agreed to by being on the roster.

Access links

Anyone holding a link has that role — send each to the right group only. One link works on any number of phones, so three operators sharing a role can share its link. Issue one each instead when you need to cut one person off without taking the others off the air, and label them so you know which is which.
